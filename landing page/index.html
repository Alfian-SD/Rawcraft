Questions

What is RawCraft?

RawCraft is a custom Minecraft launcher for Windows.

Does RawCraft support mods and mod loaders?

Yes. You can install mods directly from Modrinth, with built-in support for Fabric, Quilt, Forge, and NeoForge.

Which Windows versions are supported?

Windows 10 and 11. Confirm exact support in the release notes once published.

How do I install it?

Download the installer, run it, and follow the prompts.

What do I need to use it?

A Windows PC and a Minecraft license. The launcher doesn’t include the game.

How do updates work?

Update details will be listed with each release.

Something isn’t working. What now?

Re-download the installer and try again. Support links will be added when available.

Do I need to own Minecraft?

Yes. You need your own Minecraft account and license to play.
